2. Base Rules for Tens (10-99)

  • 10: wäl
  • 11–19: wäl + [digit] (e.g., 11 = wäl kɛl)
  • 20–99: jiɛn da̱ŋ + [multiplier] + wi̱dɛ + [remainder]
    • Example: 20 = jiɛn da̱ŋ rɛw
    • Example: 25 = jiɛn da̱ŋ rɛw wi̱dɛ dhieec

3. Base Rules for Hundreds (100-999)

  • 100–199: kuɔ̱r kɛl (+ wi̱dɛ + remainder)
  • 200–999: kur + [multiplier] + wi̱dɛ + [remainder]
    • Example: 200 = kur rɛw
    • Example: 350 = kur diɔ̱k wi̱dɛ jiɛn da̱ŋ dhieec
